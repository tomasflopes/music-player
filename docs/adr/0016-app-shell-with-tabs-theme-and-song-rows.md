# 0016: App shell with bottom tabs, one theme and a shared song row

Date: 2026-11-13 · Status: accepted · Supersedes 0011

**Context.** ADR 0011 put everything on one `LibraryScreen` with one `LibraryViewModel` until real navigation existed. Design 8.2 and 10 now call for tabs, a mini-player above them and a design system that later screens reuse. Two stashes, kept as `wip/ui-theme` and `wip/ui-search-recovery`, hold earlier attempts: the first has a usable theme and rows, the second references an `AppShell` that was never written and is reference only.

**Decision.** `AppShell` shows a folder prompt until a music folder is saved (a stand-in for onboarding, plan Task 23), then a Material 3 `NavigationBar` with Home and Library over a `NavHost`, with the mini-player directly above the bar. Routes are plain strings from `TopLevelDestination`; Search (ADR 0012) and later tabs are one more entry. Each destination has its own ViewModel, which talks only to `:core:model` ports and `PlaybackController`. Picking a folder goes through the new `MusicRootResolver` port, implemented in `:data` over `TreeUriMapper`, so `ui` no longer imports `:data`. The theme (fixed dark and orange scheme, type scale, `Spacing`, `ArtSize`) and the stateless `SongRow`, `AlbumArt`, `ScreenTitle` and `EmptyState` come from `wip/ui-theme`, tidied. Covers load through `CoverArtLoader` over `ContentResolver.loadThumbnail`, cached in memory per album. Coil is not added: it has no fetcher for covers embedded in audio files (the stash handed it the song URI), so it would need a custom one on top of its own dependency. New dependencies: `navigation-compose` and `hilt-navigation-compose` (already pinned) and `material-icons-extended` (managed by the Compose BoM).

**Consequences.** Two parts of plan Task 22 are deferred: typed routes, until the first route with an argument (album or artist) brings kotlinx-serialization, and the Coil fetcher, unless scrolling 16k songs janks on the phone (Task 31). Only Home and Library exist, and Library lists songs without the A-Z rail. Palette and type scale are the stash's and still need the owner's review (Task 21). `:app` has no onion rule (ADR 0013), so "ui does not import `:data`" holds by convention. Not verified here: `./gradlew check` and everything on a device.
